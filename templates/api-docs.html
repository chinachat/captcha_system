滑动拼图

        

          

            POST
            /api/v1/captcha/slider/generate
          

          

            
生成滑动拼图。返回 token、background、puzzle、puzzle_y（块 top，已减 pad）。

            

              
              
            

            

              

              

            

            

              
              
            

            

          

        


        

          

            POST
            /api/v1/captcha/slider/verify
          

          

            
校验滑动结果。需上报轨迹与耗时以通过行为检测。

            

              
字段类型说明

              
                
tokenstring生成接口返回

                
offset_xnumber拼图块左上角 x（原图像素）

                
duration_msnumber滑动耗时（毫秒）

                
trackarray[{x, t}, ...] 轨迹采样

              
            

            

              
              
            

            

              

              

            

            

              
            

          

        

      


      
      

        
点选验证

        

          

            POST
            /api/v1/captcha/click/generate
          

          

            
生成点选图。返回 image、chars（需按序点击）、prompt、token。

            

              
              
            

            

              

              

            

            

              
              
            

            

          

        


        

          

            POST
            /api/v1/captcha/click/verify
          

          

            
校验点击坐标。坐标为原图像素；容差约 28px。

            

              
字段类型说明

              
                
tokenstring生成接口返回

                
pointsarray[{x, y}, ...] 与 chars 顺序一致

                
timingsarray各次点击相对毫秒
