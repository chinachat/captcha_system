# 字体目录

将支持中文的字体文件放在此目录，程序会自动加载。

推荐（任选其一）：
- `NotoSansSC-Regular.otf`（思源黑体 / Noto Sans SC）
- `wqy-microhei.ttc`（文泉驿微米黑）
- `SourceHanSansSC-Regular.otf`

下载示例：
- https://github.com/adobe-fonts/source-han-sans/releases
- 或系统安装：`sudo apt install fonts-noto-cjk fonts-wqy-microhei`

Docker 镜像已通过 `fonts-noto-cjk` 安装系统字体，一般无需再放文件。
